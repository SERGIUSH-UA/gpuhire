# gpurunner як модуль оренди Нишпорки

Нишпорка (`nyshporka`) читає рукописні архівні справи й уміє робити це на чужій
машині по SSH. gpurunner додає їй спосіб таку машину **дістати**: орендує бокс
на Vast.ai, а після роботи гасить його. Від людини потрібні ключ API Vast і
гроші на балансі — більше нічого.

## 1. Що робить плагін, а що — ні

Пакет оголошує entry point у групі `nyshporka.cloud`:

```toml
[project.entry-points."nyshporka.cloud"]
vast = "gpurunner.plugins.nyshporka_cloud:VastRent"
```

Нишпорка знаходить його сама, щойно обидва пакети стоять в одному оточенні
(`pip install "gpuhire[vast,r2]"` поруч із Нишпоркою), і бекенд `vast`
з'являється в `nysh cloud` поруч із вбудованим `ssh`.

| крок | хто |
|---|---|
| перевірити ключ API й баланс | gpurunner |
| підібрати оферту: скоринг «сторінок за долар», реєстр боксів, стеля ціни | gpurunner |
| створити інстанс, прив'язати SSH-ключ, дочекатись SSH | gpurunner |
| звести на боксі таймер самознищення | gpurunner |
| з'єднання, проба заліза, середовище рушіїв, заливка, прогін, забір, звірка | Нишпорка (по SSH) |
| знищити інстанс, записати спостереження в реєстр боксів | gpurunner |

R2/Cloudflare на цьому шляху не потрібен: кадри їдуть на бокс по SFTP. Job'ів
gpurunner (`htr_case`) і наглядача (`gpurunner htr supervise`) цей шлях не
використовує — це окремий, самодостатній конвеєр для тих, хто має R2.

## 2. Що потрібно від людини

1. Акаунт на <https://cloud.vast.ai/> і гроші на балансі (оренда погодинна;
   справа на тисячу сторінок коштує центи, мінімум для старту — $0.50).
2. Ключ API: Account → API Keys. Зберегти одним зі способів:

   ```
   nysh cloud rent login                 # з боку Нишпорки
   gpurunner auth vast --key <КЛЮЧ>      # або `--key -` і ключ у stdin
   gpurunner auth vast --verify          # перевірити: пошта, баланс
   ```

SSH-ключ заводити не треба: якщо його немає, перша оренда згенерує пару сама.

⚠ Якщо в акаунті Vast вибрано дефолтний **темплейт** (cloud.vast.ai →
Templates), він накладається на кожну оренду й може зламати її ще до контейнера.
Дефолтного темплейта бути не повинно, або він мусить бути робочим.

## 3. Де лежать ключі

| що | де |
|---|---|
| ключ API | `<config>/vast_api_key`, права 0600 (на Windows — ACL профілю). Змінна `VAST_API_KEY` має пріоритет над файлом |
| SSH-ключ | `GPURUNNER_VAST_SSH_KEY` → `~/.ssh/id_ed25519` → `~/.ssh/id_rsa` → згенерований `<config>/vast_ssh/id_ed25519[.pub]` |

`<config>` — `GPURUNNER_CONFIG_DIR`, без змінної `%APPDATA%\gpurunner` (Windows)
або `~/.config/gpurunner`. Наявний ключ не перезаписується ніколи; свій ключ у
`~/.ssh` завжди має пріоритет над згенерованим. На Vast іде лише публічна
половина. Ключ API не друкується й не потрапляє ні в лог, ні у стан заходу: у
`Box.meta` лежить лише **шлях** до приватного SSH-ключа.

## 4. Страховка грошей

Vast тарифікує, поки інстанс не **знищено**. Тому:

- **Баланс перевіряється до пошуку.** Менше ніж `min($0.50, бюджет / 4)` —
  оренда не починається («поповніть баланс Vast»). Невідомий баланс (API не
  відповів) оренди не спиняє й нулем не вважається.
- **Незнімна стеля ціни** `$0.365/год` на карту стоїть у самому запиті до ринку
  й ще раз — перед створенням інстансу. `max_price_usd_h` може її лише знизити.
- **Будь-який збій після створення інстансу гасить його** до того, як помилка
  піде нагору, — зокрема Ctrl+C під час очікування SSH. Один `acquire` створює
  щонайбільше 3 інстанси; кожна невдала спроба лягає в реєстр боксів.
- **Таймер самознищення на самому боксі.** onstart інстансу спить
  `max_hours + 1` годину (не задано — 8 + 1) і знищує інстанс через API Vast
  ключем контейнера (`CONTAINER_API_KEY`), повторюючи спробу щохвилини. Домашня
  машина може померти, ноутбук — закритись: бокс погасить себе сам. Мить
  дедлайну лежить у `Box.meta["autodestroy_at"]`.
  🔴 Таймер жорсткий: стоп-крана немає, забір мусить вкластись у запасну годину.
- **`release` ідемпотентний**, на мертвому інстансі мовчить, а на живому, який
  погасити не вдалось, — кидає помилку з номером інстансу. Бокс із чужою міткою
  (не `nysh-rent-…`) не гаситься.

## 5. Як перевірити, що нічого не горить

```
gpurunner burn            # усе, що зараз тарифікується на акаунті
gpurunner burn --json     # {"active": N, "burn_usd_per_hour": …, "instances": […]}
```

Питає Vast напряму, повз будь-який локальний стан, тож бачить і бокс, що
лишився від убитого процесу. Орендовані для Нишпорки мають мітку `nysh-rent-…`.
Погасити: `nysh cloud stop <захід>` (а коли стану заходу вже немає — кнопкою в
<https://cloud.vast.ai/instances/>). Те саме повертає плагін у
`status()["burning"]`.

## 6. Реєстр боксів

Оренди Нишпорки пишуть у той самий реєстр, що й наглядач
([README §7](../README.md#7-реєстр-боксів)): забанені машини не беруться, зіркові
шукаються адресно й ідуть першими. Вердикт завершеної оренди задає `why` у
`release`:

| `why` | запис |
|---|---|
| `ok…` (у тексті можна дати `pph=<стор/год>`) | `ok` — машина стає зірковою |
| `failed:<деталь>` | `setup_failed`, або вирок, названий першим словом деталі (`died_under_load`, `host_destroyed` …) |
| `slow:<деталь>` | `slow_run`, або вирок першим словом (`slow_net`, `cpu_lie`, `card_busy` …) |
| решта | `user_stop` — нейтрально |

Тривалість і вартість рахуються з `rented_at` і `price_usd_h`.

## 7. Налаштування

| змінна | зміст |
|---|---|
| `GPURUNNER_VAST_RENT_IMAGE` | образ контейнера замість `pytorch/pytorch:2.4.1-cuda12.1-cudnn9-runtime` |
| `GPURUNNER_VAST_SSH_KEY` | шлях до приватного SSH-ключа |
| `VAST_API_KEY` | ключ API; має пріоритет над файлом |

Форма `Box.meta` і необов'язкові методи `status / login / estimate` —
[`contract.md` §6](contract.md#6-плагін-nyshporkacloud).
